How do we make every source traceable, like unit tests?

Every claim gets a test. The test says: "this exact sentence is on this page, and it contains this number." A script opens every page in a real browser and runs all the tests. A claim is "verified" only while its test passes.

The problem today

  • "Verified" means different things in different groups. In some, a researcher read the page once. In others, a second checker confirmed it.
  • Nobody can see why a figure is marked verified.
  • A reader can't check a claim without hunting through the source.

How the system works

  1. Claim list. Every figure, date, person's post, tie and court outcome gets a permanent id, for example e4-19/fig/2 (Vale's sale price).
  2. Evidence. Each claim stores the source link, the exact quote from the source that supports it, where on the page it is (page number for PDFs), and the date it was read.
  3. Snapshot. A script opens each source with Playwright (a real browser) or reads the PDF, then saves the text and a fingerprint (hash). If the page later changes or dies, we see it.
  4. Test run. verify.py checks every claim: is the quote on the saved page, and is the number inside the quote? The result is a test report, like software tests.
  5. Repair. Failing claims go to a researcher. They find the right source, record the new quote, and the test runs again.
  6. Open to readers. Every pill on the study pages links to its claim here: quote, source, archive copy, date, result. The whole claim list can also be downloaded as a spreadsheet file.

The four marks

MarkMeans
verifiedA researcher recorded the exact quote, and the test finds the quote and the number on the saved source.
auto-matchThe script found the number on the source page, but no one has confirmed it's the right sentence yet.
failingThe quote or number isn't on the page, or the page is dead. It needs a new source.
uncheckedNo evidence recorded yet.

Marks are computed by the script, never typed by hand. That's what makes them the same everywhere.

Steps

  1. Done (2 Nov): build the claim list, the snapshot script and the test runner. Take snapshots of every source.
  2. Next: researchers write evidence for every claim, group by group, and fix failing sources.
  3. The study pages show the computed marks and link each one here.
  4. Re-run the tests any time. A source older than 12 months gets re-checked.
